# Latitud Solutions

## Descripción
Latitud Solutions es una página web desarrollada como
parte de un examen académico sobre creación de páginas
web y uso de Git y GitHub.

La página presenta los servicios tecnológicos de la
empresa y su información de contacto.

## Servicios
- Desarrollo Web
- Soporte Técnico
- Redes

## Tecnologías utilizadas
- HTML5 para la estructura de la página.
- CSS3 para los estilos y el diseño visual.
- Git para el control de versiones.
- GitHub para alojar el repositorio.

## Estructura del proyecto
- index.html: estructura principal de la página.
- styles.css: estilos visuales de la página.
- README.md: documentación del proyecto.
